# Contributing to Free AI Gateway

Maintained by **Mourad Soltani — AGI Architect**.

## Setup

    git clone https://github.com/mouradsoltani/free-ai-gateway
    cd free-ai-gateway
    ./install.sh
    source venv/bin/activate
    pip install -e ".[dev]"

## Workflow

1. Fork and branch: `git checkout -b feat/your-feature`
2. Write tests in `tests/`
3. Run `make lint test`
4. Open a PR

## Commit style

Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`
